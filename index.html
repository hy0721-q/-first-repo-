这段时间搭起来的开发环境

从完全没接触过，到能独立提交并推送代码，按顺序走通了这几步。

第 1 步

VSCode 编辑器

装好编辑器与中文语言包，用它新建、编辑并保存项目文件，熟悉基本界面。

第 2 步

Git 版本管理

配置用户名与邮箱，学会初始化仓库、暂存改动和提交，给每次修改留下记录。

第 3 步

GitHub 远程仓库

完成账号授权，把本地代码推送到远程仓库，让成果在云端也能看到。
